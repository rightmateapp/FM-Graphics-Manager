# FM Graphics Manager

**Mix, match and fine-tune your FM graphics, and undo anything in one click.**

A small, free app for Football Manager graphics: skins, facepacks, logos and kits. Drop in the packs you download, try them one by one, combine them, and go back to the original game whenever you like.

Free for everyone, on Mac and Windows. Works with FM26 and FM27.

## Download

Get the latest version from **[Releases](../../releases/latest)**:

- **Mac** (macOS 14 or later): `FM Graphics Manager <version>.dmg`
- **Windows** (64-bit): `FM-Graphics-Manager-Windows-<version>.zip`

## Install

**Mac:** open the `.dmg` and drag FM Graphics Manager into Applications. The app is signed and notarized by Apple.

**Windows:** unzip and run `FMGraphicsManager.exe`. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

## What it does

- **Add packs:** drop a downloaded zip or folder in, and the manager puts it in the right place.
- **Switch packs** on and off, one at a time or several together.
- **Merge packs:** when two packs cover the same player or club, you pick which picture to keep.
- **Skins:** one skin at a time. The original game files are backed up first and can be restored in one click.
- **Colour tweaks:** adjust a few skin colours (buttons, borders, attribute levels) without changing the skin itself.

## What it doesn't do

- It never touches your saves, the match engine or the game's data. It only changes how the game looks.
- It doesn't host or share anyone's graphics. You download packs from their makers, and the credit stays with them.
- It only goes online when you choose to send us a problem report. You see exactly what will be sent before it goes.

## Problems?

Use **Report a problem** in the app.

## For skin makers

Players can fine-tune a few colours (buttons, borders, attribute levels) on top of your skin. It stays on their own computer, never changes your files, and is credited as "Skin by [you] · colours tweaked by you".

Don't want this for your skin? Add a file called `fmgm.json` to your skin folder containing `{"colourTweak": "deny"}`.

Want to offer your own colour presets? Add them to the same `fmgm.json` and they'll appear in the manager.
